# Automotive Sales Performance Dashboard

## Overview

This project showcases an interactive Microsoft Excel dashboard built to analyse automotive sales performance.

The dashboard uses:

- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Interactive Filtering
